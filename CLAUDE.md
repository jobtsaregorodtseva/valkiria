# Валькирия — контекст проекта

## Продукт
Голосовой ИИ-диспетчер для охранных служб (ЧОП, СБ предприятий, охрана БЦ/ТЦ/ЖК).
Ассистента зовут **Валя**. Десктоп-приложение для Windows (Python, PySide6): принимает звонки
(Asterisk, SIP, микрофон), распознаёт речь (Vosk), понимает запрос языковой моделью
(локально через llama.cpp или облачная через OpenAI-совместимый API), выполняет действия
в базе (21 инструмент), отвечает голосом. Разделы программы: Главная, Валя (чат),
Система докладов, Объекты и сотрудники, События и отчёты, Звонки, Логи.
Статус — MVP. Прежнее рабочее название — «Артемида» (ассистент «Арта»), на сайте не используем.

## Этот репозиторий
Лендинг (статический, `src/` → `dist/` через `scripts/build.mjs`) и боты предзаписи
(`api/telegram.js`, `api/max.js`) на Vercel. Подробности деплоя — README.md.
Журнал обновлений — `content/updates/*.md`, публикуется коммитом в `main`.

## Данные
Боты хранят числовой ID мессенджера, номер в списке, время, метку источника,
название организации и ответы на 5 вопросов-кнопок
(Upstash Redis). Имя, юзернейм, телефон, переписку — не сохраняем. Удаление — `/stop`.

## Дизайн
Повторяет интерфейс программы: почти чёрный фон, персиковый акцент `#f7b78f`,
моноширинные подписи (JetBrains Mono), основной шрифт Onest, цветные «клавиши» разделов.
Шрифты свои (`/fonts`), без Google Fonts. Избегать признаков «сгенерированного» дизайна:
градиентов, свечения, эмодзи-иконок, шаблонных слоганов.
